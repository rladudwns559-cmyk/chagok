차곡 소개·다운로드 사이트

파일 구성 (모두 한 폴더에)
- index.html : 첫 화면 (3D 장면은 three.js r128을 cdnjs에서 불러옴)
- how.html, features.html, download.html : 순공 세는 법 / 기능 / 다운로드
- style.css, tilt.js : 공통 디자인, 화면 기울기 효과
- *.png : 앱 화면 캡처(예시 데이터), 아이콘
- chagok-windows.zip : 내려받는 앱 파일 (bin/차곡.exe 포함)
- favicon.ico

배포: GitHub Pages (저장소 rladudwns559-cmyk/chagok, main 브랜치 / root)

새 버전을 낼 때
- chagok-windows.zip 을 새 zip으로 바꾸고, index.html 과 download.html 의 버전·용량 글자를 고치기

참고
- 화면 캡처는 예시 데이터로 찍은 것이에요(실제 사용자 기록 아님).
- 코드 서명이 없는 exe라 처음 실행할 때 Windows SmartScreen 창이 뜰 수 있어요. 다운로드 페이지에 안내가 들어 있어요.
